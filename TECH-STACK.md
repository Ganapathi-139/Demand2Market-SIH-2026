## Why This Stack?

### React + TypeScript

Provides a maintainable and type-safe frontend.

### Supabase

Provides database, authentication, realtime communication and serverless backend functionality without managing traditional servers.

### PostgreSQL

Provides reliable relational data storage and strong data integrity.

### Edge Functions

Keep sensitive backend operations and AI credentials away from the browser.

### Recharts

Provides interactive demand visualization.

### Vercel

Provides fast global frontend deployment and automatic builds from Git.
